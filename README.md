# Nanonigit Vibe

## How do I install these formulae?

`brew install nanonigit/vibe/<formula>`

Or `brew tap nanonigit/vibe` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "nanonigit/vibe"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
